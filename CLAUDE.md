## Working with another coding agent

When a local `.collaboration/handoff.md` is present, read it for the current task, file ownership, and validation status. It is local coordination, not engineering evidence. Claim the files you will edit before starting. Do not overwrite another agent’s changes, change branches, commit, or publish while a collaborator owns integration. Report exact changed files and checks actually run.

The primary product workflow is raw report plus Mathcad template, inspect/validate inputs, then generate calculated outputs. Ask is a separate, persistent destination accessible before, during, and after calculations. Reference documents support Ask; they are not a prerequisite for conversion.
